Installation Guide

Install in Under 2 Minutes

  1. Download the plugin .zip file from this page
  2. Open your JetBrains IDE (IntelliJ, PyCharm, WebStorm, etc.)
  3. Go to File → Settings (or Preferences on macOS)
  4. Navigate to Plugins
  5. Click the ⚙ gear icon in the top right
  6. Select Install Plugin from Disk…
  7. Choose the downloaded scrumb-plugin.zip file
  8. Restart the IDE when prompted
  9. Scrumb will appear in the IDE right sidebar panel

Why an IDE Plugin?

Most agile tools live in a separate tab — Jira, Linear, Notion. That's fine for project managers, but developers lose flow every time they switch. Scrumb's philosophy is that sprint intelligence should live where the work happens.

By operating as a JetBrains plugin, Scrumb can also observe development activity directly, which enables smarter blocker detection and more accurate progress tracking than any external tool can offer.

Is It Free?

Yes — during early access, Scrumb is completely free. The goal right now is to get the plugin into the hands of real teams so we can build features that actually matter.
