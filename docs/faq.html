Frequently Asked Questions

Everything you need to know about Scrumb, the JetBrains plugin, and how it helps agile teams.

What is Scrumb? ▼
Scrumb is an AI-powered Scrum Master designed for agile developer teams. It helps teams plan sprints, detect blockers early, and track progress — all directly inside your JetBrains IDE. It's built for teams that need structure but don't have a dedicated Scrum Master.
Is Scrumb free to use? ▼
Yes — Scrumb is completely free during early access. Download the JetBrains plugin at no cost. Future pricing plans may be introduced as the product matures, but early access users will always be grandfathered in.
Which JetBrains IDEs does Scrumb support? ▼
The plugin works with IntelliJ IDEA, PyCharm, WebStorm, GoLand, and other JetBrains IDEs that support the standard plugin installation from disk. See the JetBrains plugin page for full installation instructions.
Who is Scrumb designed for? ▼
Scrumb is built for student teams running capstone or hackathon projects, early-stage startups without a dedicated Scrum Master, and small engineering squads that want better sprint visibility without heavy tooling overhead.
What does an AI Scrum Master actually do? ▼
Scrumb's AI assists with sprint planning (story breakdowns, timeline estimation, workload balancing), detects blockers before they derail the sprint, and provides continuous progress tracking — all without manual check-ins or status updates. Learn more on the AI Scrum Master page.
Does Scrumb integrate with Jira or other project management tools? ▼
Jira integration is on the roadmap. The current early access plugin operates independently inside your JetBrains IDE. Integrations with popular project management and issue tracking tools will be added as the product grows.
Is Scrumb available on VS Code or other editors? ▼
Not yet. The current focus is on the JetBrains plugin ecosystem. VS Code and other editors are being considered for future releases based on user demand.
How is Scrumb different from using ChatGPT for sprint planning? ▼
ChatGPT is a general-purpose tool — it can help draft sprint goals or decompose stories if you prompt it correctly. Scrumb is purpose-built for agile workflows and lives inside your IDE, meaning it can observe your actual development activity and provide contextual, real-time sprint intelligence rather than one-off responses.
Where can I find documentation for the plugin? ▼
See the Scrumb Documentation page for installation and usage instructions. The JetBrains plugin page also has a step-by-step installation guide.
