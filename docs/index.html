JetBrains Plugin (Early Access)

Try the Scrumb JetBrains plugin — a very early demo that brings AI-powered sprint assistance directly inside your IDE.

Download Plugin (.zip)
Installation Instructions:
  1. Download the plugin zip file above.
  2. Open your JetBrains IDE (IntelliJ, PyCharm, WebStorm, etc.).
  3. Go to Settings.
  4. Navigate to Plugins.
  5. Click the ⚙ Settings icon.
  6. Select Install Plugin From Disk.
  7. Select the downloaded .zip file.
  8. Restart the IDE when prompted.
